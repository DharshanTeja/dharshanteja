### 🚀 Featured Engineering Projects

#### 🧠 [Pragna Setu — First-Principles AI Socratic Engine](https://pragnasetu.in/)
- **Architecture**: Next-generation pedagogical learning platform built for Class 10–12, JEE, NEET, and B.Tech curricula.
- **Key Innovation**: Tri-Agent Socratic architecture (*Acharya* for natural sciences, *Manthan* for mathematical logic, *Yantra* for computer science) enforcing guided inquiry and preventing direct-answer leakage.
- **Performance**: Sub-240ms Time-to-First-Token (TTFT), 94.2% answer-leakage reduction, and real-time theory-synchronized reading room with auto-generated PDF notes.
- **Tech**: React 19, TypeScript, Python, LLM Orchestration, Tailwind CSS, Socratic Reasoning Pipelines.

#### 🎮 RoyalRP — FiveM Distributed Architecture & Micro-Economic Engine
- **Architecture**: Zero-trust virtual economy framework for high-concurrency multiplayer GTA V roleplay environments.
- **Key Innovation**: Eliminated client-side monetary exploit surface with four-tier zero-trust validation across 287+ authenticated FastAPI routes. Built **RoyalOS** (19 native apps in React 18) and deployed U2-Net ONNX for edge salient asset matting.
- **Performance**: Maintained locked 64-tick server rate with 4.2ms peak tick under 300+ concurrent simulated players.
- **Tech**: FiveM, Lua, React 18, Node.js, Python, FastAPI, ONNX Runtime, MySQL.

#### ⚡ Nexus Game Panel
- **Architecture**: Modern distributed game server orchestration management dashboard.
- **Key Innovation**: Overcame complex API-to-container synchronization hurdles with non-blocking event loops, enabling automated server lifecycle orchestration.
- **Tech**: TypeScript, React, Tailwind CSS, Python, MySQL, Docker.

#### 🤖 Discord Bot Ecosystem
- **Architecture**: High-performance suite of Python automation bots for community moderation, game server integration, and media streaming.
- **Key Innovation**: Resolved critical Minecraft RCON kick loops via packet synchronization fixes, and engineered custom audio streaming overrides for LavaSrc stability.
- **Tech**: Python, Discord.py, RCON Protocol, LavaSrc, MySQL.

#### 🏢 [Harey Bharath Corporate Platform](https://hareybharath.com)
- **Architecture**: Official corporate web ecosystem for Harey Bharath Services, architected for recruitment management and client onboarding.
- **Key Innovation**: Spearheaded legacy HTML/CSS migration to a type-safe React + TypeScript foundation with unified responsive design.
- **Tech**: React, TypeScript, Tailwind CSS, Node.js.

#### 🛍️ [Mycan — Heritage E-Commerce Platform](https://mycan.in)
- **Architecture**: Luxury e-commerce brand platform for a 65-year heritage fruit products brand.
- **Key Innovation**: High-fidelity visual storytelling, optimized cinematic media delivery, and smooth product discovery UX.
